# AI-Based Intrusion Detection System (AI-IDS)

## 1. Project Title

**Development of an AI-Based Intrusion Detection System Using Machine Learning and Comparative Evaluation Against Traditional IDS (Snort and Suricata).**

## 2. Project Overview

This research project aims to develop an intelligent Intrusion Detection System (IDS) using machine learning techniques to identify malicious network traffic and detect potential cyberattacks.

The proposed system will analyze network traffic datasets, extract relevant features, train machine learning models, and classify network activities as benign or malicious.

The performance of the proposed AI-based system will be experimentally evaluated and compared with traditional intrusion detection systems, specifically Snort and Suricata.

## 3. Research Problem

Traditional signature-based intrusion detection systems primarily depend on predefined rules and known attack patterns. Although these systems are effective in identifying recognized threats, detecting previously unseen or evolving attacks remains challenging.

Machine learning provides an alternative approach by learning patterns from network traffic data and identifying potentially malicious activities.

This research investigates whether machine learning techniques can improve intrusion detection performance while considering detection accuracy, false positive rates, and processing time.

## 4. Research Objectives

1. Develop an AI-based intrusion detection system using machine learning.
2. Analyze and preprocess network traffic datasets.
3. Train and evaluate multiple machine learning algorithms.
4. Detect benign and malicious network activities.
5. Evaluate traditional IDS solutions using Snort and Suricata.
6. Compare the systems using standardized evaluation metrics.
7. Develop a dashboard for presenting detection results and performance measurements.

## 5. Research Methodology

The research will follow an experimental methodology consisting of the following stages:

1. Dataset acquisition.
2. Data preprocessing and feature engineering.
3. Machine learning model development.
4. Model training and testing.
5. Traditional IDS configuration and testing.
6. Experimental performance evaluation.
7. Comparative analysis and visualization.

## 6. Dataset

The CICIDS2017 dataset will be investigated as the primary dataset for model development and evaluation.

It contains labeled network traffic representing benign activities and multiple categories of cyberattacks.

Dataset suitability, feature availability, data quality, and licensing conditions will be examined before experimentation.

## 7. Machine Learning Algorithms

The following algorithms will be investigated:

- Decision Tree
- Random Forest
- XGBoost
- Isolation Forest
- Multi-Layer Perceptron (MLP)

Their suitability and performance will be evaluated experimentally.

## 8. Traditional Intrusion Detection Systems

The research will include two established intrusion detection systems:

- Snort
- Suricata

Both systems will be configured and evaluated using a documented and repeatable testing methodology.

## 9. Evaluation Metrics

The experimental evaluation will consider:

- Accuracy
- Precision
- Recall
- F1-Score
- False Positive Rate (FPR)
- Detection Time
- Computational Resource Usage

## 11. Expected Outcomes

The expected outcome is a functional research prototype of an AI-based intrusion detection system, supported by experimental results and a comparative evaluation against traditional IDS solutions.

The research will identify the strengths, limitations, and practical trade-offs of the evaluated approaches without assuming that one system will outperform the others.

## 12. Research Scope and Safety

All experiments will be conducted using authorized datasets and controlled laboratory environments. No unauthorized network access or attacks against third-party systems will be performed.
